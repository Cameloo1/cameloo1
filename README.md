## 🪐 About Me

I'm Wasif, a self-taught engineer based in Chicago. I build software that 
sits between AI agents and the systems they touch — local-first 
infrastructure that makes agent operations verifiable rather than just 
plausible. I'm motivated by the gap between what looks like it works and 
what actually does, and most of my projects exist to close that gap.

I enjoy systems work and applied infrastructure (typed program graphs, 
MCP servers, evidence layers, retrieval engines) and I'm drawn to 
lower-level problems when the higher-level abstraction is hiding something 
important. Rust for cores, TypeScript for adapters, Python and Go when 
the task asks for them. I care a lot about honest documentation — most of 
my READMEs include a "what this does not yet do" section because I'd rather 
be trusted than impressive.

On GitHub you'll find projects that follow that pattern. codegraph-mcp is 
a local code-graph evidence layer for AI coding agents. agent-search-tool 
is an 8-stage retrieval pipeline with Bayesian reliability scoring. 
agent-relaybase is an MCP router for managing local dev servers. I work 
iteratively — ship something honest, find where it breaks, refine it 
until the broken parts become the documented edges.

Outside of building, I trade ES futures (six years in markets) and came up 
through cybersecurity work — SIEM, IAM, threat modeling. Both backgrounds 
shape how I think about agent infrastructure: markets taught me that 
unverified context becomes loss, and security taught me that systems fail 
at the integrity layer, not the feature layer.

I'm currently pushing codegraph-mcp toward broader external testing, 
building Typai (an embeddable writing intelligence layer), and thinking 
hard about the deterministic bridges between AI intent and real-world 
infrastructure.
